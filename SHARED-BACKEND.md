# Общая база меню и админки

С 2026-10-02 клиент загружает каталог из `https://sharim.176-222-53-108.sslip.io/api/catalog`. Актуальный источник товаров и цен — существующий Postgres, таблица `menu_products`. Из `menu-data.js` клиент использует только `imageFor`; массив товаров там — исходные данные, не текущий каталог. Изменение этого массива не меняет опубликованное меню.

Админка `/admin/` использует отдельный логин и пароль владельца: `manager-account.js`, сервер `server/src/manager_auth.rs`, миграция 0009. Покупательский Telegram-вход не изменён. Старый API-доступ по `ADMIN_TG_IDS` сохранён только для явно назначенных аккаунтов, но интерфейс админки больше не отправляет пользователя в бота.

Пароли — Argon2id с индивидуальной солью. Админские сессии отделены от клиентов, в базе хранится SHA-256 случайного токена, срок 8 часов, максимум 5 сеансов. Клиент хранит токен только в `sessionStorage`, пароль не сохраняет. Выход отзывает сеанс на сервере; смена пароля отзывает все прежние сеансы. После 5 неверных попыток вход закрыт на 15 минут; счётчик хранится в базе. До смены временного пароля доступ к данным и редактированию закрыт.

В «Меню и товары» переключатель сохраняет доступность через существующий `/manage/products`: включено = `active`, выключение = `out` (временно скрыт, без удаления). Включение архивного товара/черновика переводит его в `active`. Текущие цена, название, фото, добавки и варианты сохраняются с проверкой `version`. Повторный клик блокируется на время записи, ошибка откатывает положение; устаревшая запись не повторяется автоматически. Клавиатура: пробел/Enter или стрелки влево/вправо. База обновляется сразу, открытое клиентское меню получает каталог при загрузке и по своему периодическому обновлению.

Учётная запись создаётся только оператором на сервере: `sharim_server --create-manager admin /tmp/initial-credentials.txt` внутри контейнера с настроенной базой. Команда не перезаписывает существующего владельца, генерирует случайный временный пароль и записывает его в файл с правами 0600. Не размещать этот файл в репозитории/статике. Публичной регистрации и сброса пароля нет.

Существующий сервер и бот: `/Users/romandegtyariov/Desktop/claude/sharim-game`, серверный модуль `server/src/commerce.rs`. Миграции 0006 и 0007 опубликованы. Бот сохраняет личные контакты через внутренний `/api/bot/contact`, общая карточка определяется Telegram ID.

Не смешивать демо с продажами: текущие заказы имеют статус `demo`, оплаты, кухня, рассылки, чеки и количественный склад отключены. Реальная выручка пока нулевая. Позиции, фото и доступность редактируются в общей базе; старые заказы сохраняют историческую цену.
